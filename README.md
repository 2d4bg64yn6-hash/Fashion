# АвтоСклад — кликабельный прототип

Мини-прототип учётной платформы в духе «МойСклад» для магазина автозапчастей.
Только frontend: React + TypeScript + Tailwind CSS, демо-данные, состояние в браузере (localStorage).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + сборка в dist/
```

## Что внутри

- **Дашборд** — KPI, график продаж (14/30/60 дней), последние заказы, товары с низким остатком.
- **Товары** — поиск, фильтры по категории и статусу, карточка товара, добавление и редактирование.
- **Склад** — остатки по двум складам, операции «Приход / Расход / Перемещение / Списание», журнал движений.
- **Продажи** — заказы покупателей, создание заказа с автоподсчётом суммы, смена статуса в таблице и в карточке.
- **Закупки** — заказы поставщикам со статусами «Черновик → Заказан → В пути → Получен».
- **Клиенты / Поставщики** — таблицы, поиск, карточки с историей заказов и закупок.
- **Финансы** — доходы, расходы, дебиторка, кредиторка, баланс, журнал операций.
- **Отчёты** — продажи по товарам и категориям, остатки, движение товаров, дебиторская задолженность.

## Связанная логика

- Заказ переходит в «Оплачен» (или дальше) → в «Финансах» появляется поступление, долг клиента уменьшается.
- Заказ переходит в «Отгружен» / «Завершён» → товар списывается с Основного склада, в журнале появляется «Расход».
- Закупка переходит в «Получен» → товар приходует на Основной склад, в «Финансах» появляется оплата поставщику.
- Статус товара («В наличии / Мало / Нет в наличии») считается по остатку и минимальному остатку.

Сбросить демо-данные: **Настройки → Сбросить демо-данные**.

## Структура

```
src/
  data.ts            демо-данные и типы
  store.tsx          состояние и бизнес-действия (контекст React)
  App.tsx            боковое меню, шапка, навигация по разделам
  components/        UI-кит, график, редактор документа
  pages/             разделы платформы
```
